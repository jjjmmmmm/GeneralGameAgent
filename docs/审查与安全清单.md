## 三、密钥扫描实操记录

```powershell
# ① 仓库历史扫描（无输出 = 无命中）
cd GeneralGameAgent\GeneralGameAgent
git log --all -p --name-only 2>$null | Select-String -Pattern "api[_-]?key|secret|password|token\s*=|BEGIN (RSA|OPENSSH|PRIVATE)" | Select-Object -First 20

# ② 工作区敏感文件检查（预期无输出）
Get-ChildItem -Recurse -Include *.env,*.pem,*.key,*.p12 -ErrorAction SilentlyContinue | Select-Object FullName

# ③ 环境变量确认（serve 凭据无关，仅 HF 离线标志）
Write-Output "HF_HUB_OFFLINE=$env:HF_HUB_OFFLINE"
```

- ①结果：无命中
- ②结果：仅 `.venv/Lib/site-packages/certifi/cacert.pem` 等（Python 自带 CA 根证书，非私钥/凭据；`.venv` 不入仓）——白名单放行
- ③结果：当前会话未设（由 `_start_serve_d5.ps1` 启动时注入，仅离线标志非凭据）

**结论**：仓库无密钥/凭据；鉴权项为"不适用"（离线本地场景），理由充分。
