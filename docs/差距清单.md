- **输出**：键序映射表 + 验证脚本 + 修正后的指标
- **计划天**：D6 块 A

## G2 [P0] 200 帧全量测试集评测（M3 验收 / M4 关键）

- **约束**：测试集必须与统计集隔离（chunks 0032~0034 已划定）
- **需求**：从测试集抽 ≥200 帧，跑完评测，输出 M4 验收指标（按键准确率 ≥50%、摇杆相关系数 ≥0.4）

- **计划天**：D6 块 A

## G3 [P0] 真正"按键触发一致率"指标

- **约束**：不能用"全 0 预测"虚高准确率蒙混验收
- **需求**：在 G1/G2 基础上，加算三组指标：
  - 召回率（gt 按时模型也按 → recall）
  - 精确率（模型按时 gt 是否也按 → precision）
  - F1（综合）
- **范围**：扩展 evaluator 逻辑
- **输出**：与 G2 一同
- **计划天**：D6 块 A
