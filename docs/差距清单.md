## G11 [P0] M4 摇杆相关系数未达标（-0.095 < 0.4）——✅ D7 归因收口（不达标事实不变）

- **结论**：200 帧测试集 M4 判定保持：按键准确率 88.3% ✅；摇杆 j_left 相关系数 -0.1 ❌。**归因验证完成（D7）**：
  1. **无条件分支（确认，且不可修复）**：读 `serve.py`/`inference_session.py`/`inference_client.py` 确认——ng.pt 的 `game_mapping_cfg=None` → serve 启动走无条件分支（打印 "No game mapping available"）；predict 请求仅含 `image`，**无 game 字段接口**。模型就是无条件 zero-shot，课程范围内无法通过现有 serve 添加 game conditioning（除非换权重/重训）。
  2. **PRED_ROW 时序（排除）**：`scripts/probe_pred_row.py` 对 30 帧测试集计算全部 **18 步**（实测模型输出 18 步动作，非 8 步）与标注 j_left 的相关系数矩阵——所有步 |corr|≤0.159，无一步显著，**不存在取错步问题**，维持 PRED_ROW=0。
  3. **模型能力上限（结论）**：综合 1+2 与 200 帧数据（pred 按键事件 33 vs gt 400、摇杆与人类无相关），根因 = **无条件 zero-shot 下模型对未见游戏的摇杆预测能力上限**，非实现缺陷。
- **验收口径**：M4"摇杆相关系数 ≥0.4"未达标，如实呈现；对应立项书 R4 缓冲已消耗（结论为能力上限而非可修缺陷），D8 报告与答辩以"能力上限 + 三假设验证证据"应对。
