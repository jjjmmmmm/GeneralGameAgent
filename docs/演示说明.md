## 1. 编号步骤

### 步骤 0：进入工作区根目录

```powershell
# 所有命令都以工作区根目录为基准（_start_serve_d5.ps1、_data/、_models/ 都在这一层）
cd D:\2+课产品
```

**预期现象**：提示符变为 `PS D:\2+课产品>`。
**失败检查**：若报路径不存在，先确认工作区实际位置。

### 步骤 1：启动推理服务

```powershell
# 启动（后台运行，日志到 results/serve_d5.log）
powershell -ExecutionPolicy Bypass -File _start_serve_d5.ps1

# 探活端口（最多 60 秒）
$ok = $false
for ($i=1; $i -le 30; $i++) {
  if (Test-NetConnection 127.0.0.1 -Port 5555 -InformationLevel Quiet) { $ok = $true; break }
  Start-Sleep -Seconds 2
}
if (-not $ok) { Write-Error "serve.py 未就绪，查看 results/serve_d5.log"; exit 1 }
Write-Host "服务就绪"
```

**预期现象**：~36 秒后端口 5555 可连接（日志出现 `Server running on port 5555`）。
**失败检查**：`Get-Content results/serve_d5.log -Tail 30 -Encoding UTF8` 查看 traceback；端口占用则先 `Stop-Process -Name python -Force`（确认无其他任务再执行）。

### 步骤 2：测试集评测（快速验证 10 帧）

```powershell
cd GeneralGameAgent/GeneralGameAgent
.venv\Scripts\python.exe scripts/evaluate.py --n 10 --k 1 --out results/test_set_metrics_smoke.md
```

**预期现象**：对 10 帧真帧抽帧+推理，输出按键准确率（~88%）、触发召回率、j_left MSE/相关系数。耗时约 13 秒。
**注意**：必须带 `--out` 指定独立文件名——**不要覆盖 `test_set_metrics.md`（正式 200 帧报告）**。
**失败检查**：`Connection refused` → 服务未启动；`ModuleNotFoundError: nitrogen` → 仓库结构异常；其他 traceback 保留全部日志。

### 步骤 3：全量测试集评测（200 帧，M4 验收）

```powershell
# 前台跑约 6~7 分钟；或后台运行（见 results/evaluate_d6.log）
.venv\Scripts\python.exe scripts/evaluate.py --n 200 --k 3
```

**预期现象**：等间隔采样 200 帧（chunk_0032~0034，640~700s，与统计集隔离），每帧 K=3 次推理多数票（随机性控制）。输出：
- 按键准确率 ~88%（M4 要求 ≥50%，达标）
- 触发精确率 ~54% / 召回率 ~4.5% / F1 ~0.08
- 摇杆 j_left 相关系数 ~-0.1（M4 要求 ≥0.4，**未达标**——如实呈现，见 `docs/键序映射表.md` 第 4 节归因）
- 单帧推理均时 ~1.3s，总耗时 ~380s

**失败检查**：中途中断 → 无断点续跑，重跑全量（帧数可降 `--n 100` 快速验证链路）；zmq 超时 → 重启 serve 重试一次。

## 3. 已知限制

- **M4 摇杆相关系数未达标**（-0.095 < 0.4）：模型为无条件分支（无 game conditioning）、预测稀疏；如实报告，D7 归因验证
- **触发召回率 4.5%**：模型零样本按键行为极度稀疏（200 帧 33 键事件 vs 标注 400），准确率 88% 含大量 0==0，**验收以触发指标为准**
- **PRED_ROW=0 时序语义未严格验证**：命中法无信号（模型预测稀疏），维持官方 cfg 默认，见 `docs/键序映射表.md` §3
- **随机性**：flow matching 采样非确定，serve 无 seed 参数 → 评测统一用 K=3 多数票；单次推理结果有波动属正常
