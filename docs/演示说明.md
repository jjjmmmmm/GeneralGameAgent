## 1. 编号步骤

### 步骤 1：启动推理服务

```powershell
# 启动（脱离当前工具会话后台运行，日志到 results/serve.log）
powershell -ExecutionPolicy Bypass -File _start_serve_d5.ps1

# 探活端口（最多 60 秒）
$ok = $false
for ($i=1; $i -le 30; $i++) {
  if (Test-NetConnection 127.0.0.1 -Port 5555 -InformationLevel Quiet) { $ok = $true; break }
  Start-Sleep -Seconds 2
}
if (-not $ok) { Write-Error "serve.py 未就绪，查看 results/serve_d5.log"; exit 1 }
Write-Host "服务就绪"
```

**预期现象**：~36 秒后端口 5555 可连接，进程 PID 在 `Get-Process python` 中可见。
**失败检查**：日志最后 30 行（`Get-Content results/serve_d5.log -Tail 30`）是否出现 `Server running on port 5555`；若无但有 traceback，对照项目备忘第 5 节环境坑处理。

### 步骤 2：真帧批量推理

```powershell
# 进入仓库
cd GeneralGameAgent/GeneralGameAgent
.venv\Scripts\python.exe scripts/e2e_test.py
```

**预期现象**：依次对 5 帧真图（60~64s）调用 `ModelClient.predict`，输出每帧耗时（首帧 ~1s，后续 ~0.34s）和按键准确率（~85%）。
**失败检查**：报 `Connection refused` → 服务未启动或端口占用；报 `ModuleNotFoundError: nitrogen` → 仓库结构异常；其他 traceback 保留全部日志再排查。
