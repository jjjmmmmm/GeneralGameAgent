## 2. 主路径接口索引

> 完整定义见 `docs/数据模型与接口约定.md`。

| 模块 | 接口 | 一句话 |
|------|------|--------|
| A data_loader | `list_chunks(shard_path, game) -> list[ChunkMeta]` | 列出分片内指定游戏的 chunk 索引 |
| B frame_fetcher | `fetch_frames(chunk, out_dir) -> list[FrameRecord]` | 按 metadata 从 youtube 截帧（yt-dlp） |
| C stats | `button_stats(parquet) -> (int, dict, dict)` | (帧数, 17键占比, 17键次数) |
| D infer_client | `InferClient.predict(frame) -> ActionBlock` | ZeroMQ 走官方 serve.py 得 8 步动作块 |
| E evaluator | `run(test_frames, predictions) -> (EvalSummary, list[MetricRow])` | 按键准确率/摇杆 MSE/相关系数 |
| F viz | `render_curve(action_pairs, out_png)` | 双线对比图，≥20 段标差异帧 |
| G archive | 归档各模块输出 | 指标表 + 报告素材 |

## 5. 环境坑（持续累积）

- 工具会话拦截 pip install / 杀后台进程 → 走 `.ps1` + WMI（Invoke-CimMethod）托管 + 轮询日志
- 命令行中文路径/文件名乱码 → 一律用 UTF-8 `.py` 脚本文件操作
- git add 中文文件名失败 → 用 `git add <目录>` 或绝对路径
- HF 直连超时 → hf-mirror（下载实测可达）
- **pip extras 语法 `path[serve]` 在 WMI/cmd 里会被吞**（装成完整依赖含实机库）→ 改用显式包清单 + `-e path --no-deps`（D3 实测）
