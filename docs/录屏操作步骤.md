# 演示录屏操作步骤 + 演讲稿（G5）

> 用途：用 OBS 录制 5~10 分钟演示视频，覆盖"从零启动 → 评测 → 出指标"完整流程。
> 输出：`results/demo.mp4`（不入仓）。
> 录制前：确认 serve 已启动（步骤 0），否则录屏里会看到错误提示（也可以作为排错演示，二选一）。

## 准备（5 分钟）

1. 安装 OBS Studio（https://obsproject.com/ ），保持默认设置；
2. 打开 OBS → 左下"来源"点 + → 选"显示器采集"（推荐录全屏）或"窗口采集"（选 PowerShell 窗口）；
3. 音频：麦克风打开（讲稿用）；桌面音频可关（无背景声更干净）；
4. 录制分辨率建议 1920×1080。

## 录制流程（按序操作，每步配讲稿）

> 建议录制时把 PowerShell 窗口最大化、字体调大（`右键标题栏 → 属性 → 字体`），观众能看清命令。

### 0. 开场（约 30 秒）

【讲稿】
> "大家好，这是我的课题七《通用游戏智能体》演示。项目基于 NVIDIA 开源的 NitroGen 模型，做离线推理评测与可视化。下面我从零跑通主路径：启动推理服务、评测 200 帧测试集、查看指标与可视化对比。"

【操作】无，直接开讲。

### 1. 启动推理服务（约 1 分钟）

```powershell
cd D:\2+课产品
powershell -ExecutionPolicy Bypass -File _start_serve_d5.ps1
for ($i=1; $i -le 30; $i++) { if (Test-NetConnection 127.0.0.1 -Port 5555 -InformationLevel Quiet) { Write-Host "READY"; break }; Start-Sleep 2 }
```

【讲稿】
> "第一步启动推理服务。NitroGen 是 500M 参数的扩散模型，输入单帧游戏画面，输出手柄动作块。脚本用离线模式加载，避免联网检查。大约 40 秒后端口 5555 就绪。"

### 2. 快速验证（约 30 秒）

```powershell
cd D:\2+课产品\GeneralGameAgent\GeneralGameAgent
.venv\Scripts\python.exe scripts\evaluate.py --n 10 --k 1 --out results\test_set_metrics_smoke.md
```

【讲稿】
> "先用 10 帧做链路验证。评测脚本抽真帧、调推理服务、与人类标注对齐、算指标，十几秒出结果。按键准确率在 87% 左右——注意准确率偏高是因为模型倾向少按键、'都为零'也算对，所以真正的验收指标要看触发召回率。"

### 3. 全量评测 200 帧（约 1 分钟讲解，录制时可快进）

```powershell
.venv\Scripts\python.exe scripts\evaluate.py --n 200 --k 3
```

【讲稿】
> "正式评测用 200 帧隔离测试集，与统计集不重叠。K=3 多数票控制扩散模型的采样随机性。跑完约 6 分钟，这里快进。M4 判定：按键准确率 88.3% 达标；摇杆相关系数 -0.1 未达标——这是无条件 zero-shot 模型的能力上限，我做了三组归因实验确认，具体在报告里展开。"

### 4. 查看指标报告（约 30 秒）

```powershell
Get-Content results\test_set_metrics.md -Encoding UTF8
```

【讲稿】
> "指标报告完整：按键准确率、触发精确率/召回率/F1、摇杆 MSE 与相关系数、M4 判定。还有每帧明细可逐帧核对。"

### 5. 对比表（约 30 秒）

```powershell
Get-Content results\m5_demo_table.md -Encoding UTF8
```

【讲稿】
> "这是模型预测 vs 人类标注的逐帧对比表：帧画面、人类按的键、模型预测的键、摇杆值、一致性。可以一帧帧核对模型在哪里对、哪里错。"

### 6. 可视化曲线（约 30 秒）

```powershell
Get-Content results\figures\curves\index.md -Encoding UTF8
# 打开 results\figures\curves\seq_060.png 展示
```

【讲稿】
> "可视化工具批量生成了 21 段动作曲线。每段上栏人类按键、中栏模型预测、下栏摇杆对比，红色标注的是差异最大的 5 帧。M7 扩展目标达成。"

### 7. 结尾（约 15 秒）

【讲稿】
> "以上就是主路径的完整演示：启动、评测、指标、对比、可视化。谢谢观看。"

## 录制后

1. OBS 停止录制 → 文件在 `录像/` 目录（默认）；
2. 把 mp4 复制到 `results/demo.mp4`（或报告引用实际路径）；
3. 码率建议 8~15 Mbps，总时长控制在 8 分钟内。
